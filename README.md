# Board / ELT flash

One-page ELT / board flash from the monthly close for a fictional CPG company (**Northline Consumer Products**): Actual vs Budget vs Forecast, board KPIs with RAG, structured callouts, and a print-ready one-pager.

**File to open:** `Northline_Board_ELT_Flash.xlsx`

## What you will see

- Close-month toggle and ELT headlines on Assumptions
- P&L flash: Actual / Budget / Forecast for the close month and YTD ($ and %)
- Seven board KPIs with formula-driven Green / Amber / Red
- Callouts: what went well, attention, decisions/asks, risks, forward look
- **05_One_Pager** — the money tab: KPI tiles, compact P&L, headlines, callouts, RAG scoreboard, chart

Yellow cells with blue font are inputs. Black font is formulas.

## How to use

1. Open `01_Assumptions` and set the close month; edit headlines and RAG bands (yellow).
2. Paste or edit Actual / Budget / Forecast leaf lines on `02_P&L_Flash`.
3. Confirm board KPIs and commentary on `03_KPIs`.
4. Tighten narrative on `04_Callouts`.
5. Print / PDF `05_One_Pager` landscape — one page for the ELT pack.

## Stack

Excel (formulas only — no VBA). Built so another analyst can inherit the file from the data dictionary.
